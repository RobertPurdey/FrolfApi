A .NET API that allows account creation/login, adding friends and tracking disc golf games securely. The focus was on sending/receiving encrypted data as well as broadcasting and receiving live score updates.

The API is used by my android app, https://github.com/RobertPurdey/DiscGolfApp, and broadcaster, https://github.com/RobertPurdey/FrolfAppScoreBroadcaster.

This project is part of my BCIT bachelor practicum. See https://github.com/RobertPurdey/bcit-bachelor-practicum-documentation/blob/main/live-scoring-app-bcit-practicum-final-report.pdf for full documentation of the practicum.
